### 📱 Dex App – Android (Kotlin)

Aplicativo Android desenvolvido em **Kotlin**, que consome dados da **PokéAPI** para exibir informações detalhadas sobre os Pokémon. O projeto foi estruturado seguindo a arquitetura **MVVM (Model–View–ViewModel)**, promovendo separação de responsabilidades, maior testabilidade e facilidade de manutenção.

A comunicação com a API REST é realizada utilizando **Retrofit**, com **OkHttp** para gerenciamento eficiente das requisições HTTP, garantindo desempenho e confiabilidade no consumo dos dados. Para o carregamento e exibição de imagens, foram utilizadas as bibliotecas **Fresco** e **Picasso**, otimizando o uso de memória e a performance da aplicação.

O aplicativo demonstra boas práticas de desenvolvimento Android moderno, incluindo organização de camadas, consumo de APIs externas, manipulação de dados assíncronos e uso de bibliotecas amplamente adotadas no mercado.

**Principais tecnologias e conceitos utilizados:**
- Kotlin  
- Arquitetura MVVM  
- Consumo de API REST (PokéAPI)  
- Retrofit  
- OkHttp  
- Fresco  
- Picasso
