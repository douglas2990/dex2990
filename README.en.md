### 📱 Pokédex App – Android (Kotlin)

Android application developed in **Kotlin** that consumes data from the **PokéAPI** to display detailed information about Pokémon. The project is structured using the **MVVM (Model–View–ViewModel)** architecture, promoting clear separation of concerns, improved testability, and easier maintenance.

Communication with the REST API is handled using **Retrofit**, with **OkHttp** managing HTTP requests efficiently to ensure performance and reliability. For image loading and rendering, the application uses **Fresco** and **Picasso**, optimizing memory usage and overall app performance.

This project demonstrates modern Android development best practices, including clean architecture, external API consumption, asynchronous data handling, and the use of widely adopted libraries in the Android ecosystem.

**Main technologies and concepts used:**
- Kotlin  
- MVVM Architecture  
- REST API Consumption (PokéAPI)  
- Retrofit  
- OkHttp  
- Fresco  
- Picasso
