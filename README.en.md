### 📱 Dex App – Android (Kotlin)

Android application developed in **Kotlin** that consumes data from the **PokéAPI** to display detailed Pokémon information. The project follows the **MVVM (Model–View–ViewModel)** architecture, ensuring clear separation of concerns, improved testability, and easier maintenance.

The REST API communication is handled using **Retrofit**, with **OkHttp** for efficient HTTP request management, ensuring performance and reliability. Image loading and rendering are implemented using **Fresco** and **Picasso**, optimizing memory usage and application performance.

This project showcases modern Android development best practices, including clean architecture, REST API consumption, asynchronous data handling, and the use of well-established Android libraries.

**Main technologies and concepts used:**
- Kotlin  
- MVVM Architecture  
- REST API Consumption (PokéAPI)  
- Retrofit  
- OkHttp  
- Fresco  
- Picasso
